# 🚀 김도욱 (KIM DOWOOK) AI 프로젝트 포트폴리오 (DOWOOK.AI)

경기도 고양시에서 활동하는 AI 개발자 김도욱의 개인 AI 웹/앱 서비스 포트폴리오 웹사이트입니다.

## 🌟 주요 기능
- **Futuristic AI Tech Dark Mode**: 딥 옵시디언 다크 테마 기반 글래스모피즘(Glassmorphism) 및 네온 펄스 애니메이션 적용.
- **Pill-Shaped UI Component System**: 캡슐형 둥근 버튼(9999px) 및 AI/Dev 스택 태그 뱃지 제공.
- **나만 편집 가능한 자기소개 & 프로젝트 CRUD**: 비밀번호 인증 후 웹 UI에서 직접 자기소개 수정 및 신규 AI 프로젝트 등록/삭제 (LocalStorage 연동).
- **소셜 커뮤니케이션**: 1:1 오픈채팅, 이메일 주소 클립보드 복사, Github 연동.

## 🛠️ 프로젝트 구조
```
portfolio/
├── docs/                      # PRD & 디자인 시스템 가이드 문서

├── css/                       # 디자인 토큰, 컴포넌트, 애니메이션 스타일

├── index.html                 # 메인 웹 페이지
└── demo.html                  # 컴포넌트 데모 쇼케이스
```
